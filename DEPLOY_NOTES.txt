AXIOM Studio v2

This is a complete static website, ready for Cloudflare Pages, Netlify, Vercel static deployments, or simple local use.

Required website files:
  index.html
  styles.css
  data.js
  visuals.js
  app.js

No npm, build command or secret keys.
Deploy these five files to the root of a website.

Start routes:
  /#/            Homepage
  /#/math        Math Prerequisites — separate path
  /#/quant       Quant Academy — separate path
  /#/practice    Exercises and examinations
  /#/engineering Future SWE/DSA/System Design placeholders

Progress stays in the browser. Use Practice & Exams > Export progress for backups.
